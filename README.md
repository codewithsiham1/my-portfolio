# Siham Portfolio (React + Vite + Vanta.js)

1. Install Node.js (v18 or newer) from https://nodejs.org
2. Open this folder in VS Code, then open the terminal (Ctrl + `)
3. Run:  npm install
4. Run:  npm run dev
5. Open the link shown (usually http://localhost:5173)

Edit your name, email, services, skills and projects in `src/data.js`.
Put your CV as `public/cv.pdf`.
Deploy: npm run build, then upload the `dist` folder to Netlify.
